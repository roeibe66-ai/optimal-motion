# Optimal Motion

Premium physical rehabilitation & movement platform bridging clinical physiotherapy
with yoga, mobility, and strength training. Practitioners build personalized recovery
protocols; patients follow them through an engaging, interactive workout player.

Built with Next.js (App Router), TypeScript, Tailwind CSS, and Supabase. RTL Hebrew by
default (Rubik font).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
