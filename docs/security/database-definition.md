## 2. מטרות המאגר
1. מתן שירותי אימון, שיקום וכושר למטופלים ולמתאמנים באמצעות האפליקציה.
2. בניית תוכניות אימון אישיות ומעקב אחר התקדמות, כאבים ותגובה לאימון.
3. התאמת אימונים אוטומטית באמצעות מאמן AI.
4. התראות בטיחות למטפל על הודעות שזוהו כמצב דחוף.
5. תזכורות אימון שהמשתמש ביקש.

המידע אינו משמש לשיווק, לפרסום או למסירה לאחרים.

## 4. מבנה המאגר ומערכות

| רכיב | ספק | מיקום | תפקיד |
|---|---|---|---|
| מסד נתונים + אימות משתמשים | Supabase (PostgreSQL) | [אזור הפרויקט ב-Supabase] | אחסון כל המידע |
| שרת האפליקציה | Vercel | ארה"ב | הרצת האפליקציה ופעולות השרת |
| בינה מלאכותית | Anthropic API | ארה"ב | עיבוד הודעות מאמן ה-AI — לא נשמר אצל הספק לאימון מודלים |
| התראות | Web Push (Apple / Google / Mozilla) | ארה"ב/אירופה | העברת התראות, מוצפנות מקצה לקצה |
| התחברות חיצונית | Google OAuth | ארה"ב | אופציונלי |

**העברה לחו"ל:** כל הרכיבים מחוץ לישראל, לספקים המחויבים לרמת הגנה נאותה (תקנות העברת מידע לחו"ל). ההעברה מופיעה במדיניות הפרטיות ואושרה על ידי המשתמשים.

## 6. בקרות עיקריות
- **הפרדת מידע בין משתמשים:** Row Level Security בכל טבלה עם מידע אישי. כל משתמש רואה רק את השורות שלו, ומנהל (`is_admin()`) רואה הכול.
- **מפתחות:** מפתח השירות (service role) של Supabase ומפתח Anthropic נמצאים רק בשרת (משתני סביבה ב-Vercel) ולא בקוד או בדפדפן.
- **הצפנה:** HTTPS בכל התעבורה. ההצפנה במנוחה מנוהלת על ידי Supabase.
- **סיסמאות:** נשמרות מוצפנות (hash) על ידי Supabase Auth, ולא נגישות לנו.
